PLAYING NOTES

Z S X D C V G B H N J MNotes, lower octave (, L . ; / continue upwards)
Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 PNotes, upper octave
1Note off
0–9 A–FHex entry in the instrument / command columns
[ ]Octave down / up — on every page (PARAMS, plug-in, MIDI out, sample editor, CHORDS, SAMPLE, mixer), also with a plug-in's own window in front
- =Previous / next instrument
F4HOLD KEYS on / off: notes stay on after their keys come up (play one again to stop it)
NOTEA MIDI keyboard plays the current instrument, and records notes at the cursor when edit mode is on. MIDI 60 = C-3.
NOTESTOP pressed while already stopped is a panic: every MIDI-out instrument sends note-offs and All Notes Off.

PLAY & STOP

SpacePlay and record: plays the block (from the loop start when a loop is marked) with EDIT switched on; press again to stop, and EDIT goes off · Shift+Space the song
ReturnPlay / stop without touching EDIT: the block · Shift+Return the song · Cmd+Return the block from the cursor line
Cmd+[ / Cmd+]Loop start / end at the cursor line
F2 (hold) / Shift+F2FILL while held / latched on or off
Cmd+FFOLLOW on / off (the view moves with playback)

MOVING

Esc or \Edit mode on/off (\ is the key next to Return on a UK Mac keyboard)
ArrowsMove · Shift+↑ / ↓ 4 lines · Shift+← / → track
Tab / Shift+TabNext / previous track (in the pattern). On an instrument's pages: EDIT → EQ/FX → PARAMS → the pattern, and round again (Shift+Tab back)
PgUp / PgDn, Home / EndJump

EDITING

Delete (⌫)Clear the selection, or the field under the cursor
Shift+DeleteRemove the line (pulls the track up)
Alt+DeleteInsert a blank line (pushes the track down)
Cmd+C / X / VCopy / cut / paste the mouse selection, or the track · add Shift for the whole block
Cmd+ASelect the whole block
Cmd+BBounce the highlighted notes to a new instrument (asks NO FX, INSTRUMENT FX ONLY, MIXER FX ONLY or ALL FX)
Cmd+↑ / ↓Transpose track a semitone · add Shift for an octave
Cmd+Z / Cmd+Shift+ZUndo / redo (everywhere)
Cmd+RCAPTURE: what you just played goes into the pattern · with the instrument list (or the sequence) clicked last, it renames the instrument (or the block) instead

SONG

Alt+↑ / ↓Move the highlighted sequence positions (in the pattern)
Cmd+DDuplicate the highlighted sequence positions (sequence panel, ARRANGE)

FILES
